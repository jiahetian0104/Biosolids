To Install the Biosolids Screening Tool (BST):

(1) Right-click on BST_v2022xxxx.zip and Copy the file to your computer; select a folder you have read/write access to as the path to extract to (for example, your ‘Documents’ folder) and paste the file there. (See the manual for limitations on file location path length).

(2) Double-click on the zip file to open it.

(3) On the BST folder, right-click on Extract.

(4) Click Unzip and it will unzip to the location selected in Step 1.

(5) Close the zip file.


To use the Biosolids Screening Tool:

(1) Go to the newly created BST directory under the folder you extracted to when installing

(2) Depending one whether you are running the 32-bit or 64-bit version of MS Access, open either the BST_v2022xxxx_32bit.mdb or BST_v2022xxxx_64bit.mdb file in Microsoft Access 2013 or later. Click past the welcome/limitations screen.

(3) From the Main Menu, select Configure to select chemicals and scenarios to run. When you are done configuring, close the Configure form by clicking on the Close Form button or the X in the upper right corner of the window.

(4) From the Main Menu, select Run. This will display a box asking if you're ready to run the model. Click on Yes.

(5) Depending on how many chemicals you selected, it may take the BST some time to run (but typically less than 10 minutes). Once it's done, it will display a message "Done!" Click on OK to return to the BST Main Menu.

(6) From the Main Menu, select View Results to see the run results. You can also export them to Excel from the view screen.
